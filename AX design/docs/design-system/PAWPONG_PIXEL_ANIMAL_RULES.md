# 포퐁 픽셀 동물 원형 잠금 규칙

- 버전: `1.1.0`
- 상태: `Active`
- 최종 검토일: `2026-08-18`
- 상위 규칙: [`PAWPONG_BRAND_HARNESS.md`](./PAWPONG_BRAND_HARNESS.md)
- 현재 공식 고양이 원형: [`pawpong-cat-base-100x95.svg`](../../assets/pixel-animals/canonical/pawpong-cat-base-100x95.svg)
- Figma 제작 프레임: [`3504:103765`](https://www.figma.com/design/7VXGIjqr1eZBEmsp3OPNie/2026-pawpong?node-id=3504-103765)

이 문서는 사진이나 다른 캐릭터 레퍼런스를 포퐁의 기존 픽셀 동물 원형에
적용할 때, 레퍼런스 때문에 원형의 실루엣이나 포즈가 임의로 바뀌는 일을
방지하는 실행 규칙이다.

## 1. 용어

### 1.1 원형

서비스가 승인한 동물별 공식 SVG 형태다. 실루엣, 포즈, 얼굴 구조, 귀,
몸, 다리, 꼬리, 음영을 제외한 기본 픽셀 배치가 포함된다.

### 1.2 원형 잠금 변형

공식 원형을 유지하면서 몸색, 무늬 등 허용된 시각 속성만 레퍼런스에 맞게
바꾸는 작업이다.

### 1.3 새 형태 탐색

공식 원형과 다른 실루엣, 포즈, 표정 또는 신체 비율을 새로 만드는 작업이다.
사용자가 명시적으로 요청하고 승인한 경우에만 수행한다.

## 2. 작업 모드 결정

다음 표현이 포함되면 반드시 **원형 잠금 변형**으로 처리한다.

- `원형을 지켜서`
- `같은 형태로`
- `기존 SVG 기반으로`
- `포즈는 그대로`
- `모색 또는 무늬만 변경`
- 공식 원형 SVG와 사진 레퍼런스를 함께 제공한 요청

사진의 동물이 다른 자세를 하고 있어도 사진 첨부만으로 새 포즈 제작을
허가한 것으로 해석하면 안 된다. 사진은 기본적으로 모색, 무늬, 귀와 수염의
색 관계 등 허용 속성을 판단하는 자료다.

공식 원형이 존재하는데 요청이 모호한 경우에도 원형 잠금 변형을 기본값으로
선택한다. 새 형태 탐색은 `새로운 포즈`, `새로운 실루엣`, `식빵 자세로 변경`
등 형태 변경 의도가 명시된 경우에만 가능하다.

## 3. 공식 고양이 원형 계약

| 항목 | 고정값 |
|---|---:|
| 원형 SVG | `assets/pixel-animals/canonical/pawpong-cat-base-100x95.svg` |
| 원형 크기 | `100 x 95px` |
| 원형 논리 그리드 | `20 x 19칸` |
| 원본 path 개수 | `136개` |
| 표준 출력 캔버스 | `155 x 155px` |
| 표준 출력 그리드 | `31 x 31칸` |
| 픽셀 모듈 | `5 x 5px` |
| 출력 배치 위치 | `x=25px`, `y=30px` |
| 배경 | 투명 |

원형 SVG는 패턴 변형을 시작하는 유일한 형태 기준이다. 이전에 생성된 변형
SVG나 사진을 새로운 형태 기준으로 사용하면 안 된다.

## 4. 원형 잠금 범위

### 4.1 변경 금지

- 원형 136개 path의 추가, 삭제 또는 순서 변경
- 정규화된 `d` 기하 데이터 변경
- 귀, 얼굴, 몸, 세 발, 왼쪽 꼬리의 위치와 비율 변경
- 얼굴의 눈, 코, 입 기본 위치 변경
- 원형의 실루엣, 포즈 또는 방향 변경
- `100 x 95px` 원형 영역 및 `(25, 30)` 출력 배치 변경
- 레퍼런스 사진의 포즈를 원형에 임의로 이식

Figma 또는 SVG 변환에서 생긴 극소수 소수점 좌표는 결정론적인 5px 그리드
정규화를 적용할 수 있다. 원본과 결과 비교 시 양쪽에 동일한 정규화 함수를
적용해야 하며, 이를 새로운 형태 변경으로 이용하면 안 된다.

### 4.2 변경 가능

- 몸의 기본 색상
- 몸 안쪽의 무늬 형태와 승인된 무늬 색상
- 레퍼런스에 따른 귀 내부 색상
- 기존 형태를 유지한 수염·입 주변 영역의 색상 또는 문서화된 표시 여부
- 레퍼런스 근거가 있는 경우 기존 상단 눈 path 두 개의 색상

추가 무늬 레이어는 원형의 몸 픽셀 마스크 내부에만 배치해야 한다. 외곽,
투명 영역, 눈·코·입 또는 고정된 입 주변 영역 위로 침범하면 안 된다.

### 4.3 눈과 코·입 색상 분리 공식

공식 고양이 원형에서 기본 `#683D11` 얼굴 디테일은 위치에 따라 두 역할로
분리한다. 기하와 path 순서는 모두 잠금 상태이며 색상 허용 범위만 다르다.

| 역할 | 원형 안의 판정 기준 | 색상 규칙 |
|---|---|---|
| 왼쪽·오른쪽 눈 | 얼굴 디테일 중 상대적으로 위쪽 `y=40–45px`에 있는 두 개의 `5 x 5px` path | 레퍼런스에 따라 변경 가능 |
| 코·입 | 눈보다 아래쪽 `y=45–55px`에 있는 세 개의 얼굴 디테일 path | 항상 `#683D11` |

공식 원형의 눈은 정규화 후 다음 두 path다.

```text
왼쪽 눈:  source index 125, d="M55 40H50V45H55V40Z"
오른쪽 눈: source index 124, d="M80 40H75V45H80V40Z"
```

필수 규칙:

- 레퍼런스에서 파란색, 초록색, 노란색 등 눈동자 색이 명확한 경우에만 두 눈 path의 `fill`을 기존 승인된 일러스트 눈 색상 또는 사용자가 승인한 색상으로 변경할 수 있다.
- 눈 색 근거가 불명확하면 기본값 `#683D11`을 유지한다.
- 일반적인 동일 눈 색 고양이는 두 눈에 같은 색을 적용한다. 오드아이는 레퍼런스에서 명확히 확인되고 사용자가 해당 특징을 요구한 경우에만 좌우 색을 다르게 적용한다.
- 눈 색 변경은 기존 두 path의 `fill`과 동일 path의 inline `style`만 바꾸는 방식으로 수행한다.
- 눈을 표현하기 위해 새로운 `<path>`, `<rect>`, overlay 또는 하이라이트 픽셀을 추가하면 안 된다.
- 코·입에 해당하는 source index `130`, `131`, `132`는 레퍼런스의 눈 색과 관계없이 `#683D11`을 유지해야 한다.
- 눈과 코·입의 위치, 크기, path `d`, 순서 및 5px 그리드는 변경하면 안 된다.

적용 예시: 파란 눈이 명확한 래그돌 고양이는 상단 두 눈 path만
`#406DFF`로 변경하고, 하단 코·입 세 path는 `#683D11`을 유지한다.
여기서 `#406DFF`는 해당 일러스트의 승인된 눈 색 역할이며 UI Main 컬러로
재분류하지 않는다.

## 5. 레퍼런스 해석 규칙

1. 먼저 레퍼런스의 기본 몸색을 판별한다.
2. 무늬 위치, 크기, 대비 관계를 판별한다.
3. 고대비 모색인지 유사색 모색인지 판별한다.
4. 허용된 팔레트에서 가장 가까운 색 관계로 단순화한다.
5. 눈 색 특징이 명확한지 판별하고, 명확할 때만 4.3절의 상단 두 눈 path 색상을 결정한다.
6. 실제 털의 세부 질감은 5px 픽셀 무늬로 번역하고 그라디언트로 묘사하지 않는다.
7. 사진의 자세, 카메라 각도, 표정은 원형 잠금 변형에 반영하지 않는다.

## 6. 필수 실행 절차

원형 잠금 고양이 에셋 제작은 아래 절차를 생략하면 안 된다.

1. 브랜드 하네스와 이 문서를 읽는다.
2. 공식 고양이 원형 SVG를 읽는다.
3. 작업 모드를 `원형 잠금 변형`으로 선언한다.
4. 레퍼런스에서 변경 가능한 특징만 추출한다.
5. 기존 path는 유지하고 허용된 fill, 4.3절의 눈 색상 및 몸 내부 무늬만 적용한다.
6. `155 x 155px` 표준 캔버스의 `(25, 30)`에 원형을 배치한다.
7. SVG와 실제 크기 미리보기를 생성한다.
8. 7절의 자동 검증을 모두 통과시킨다.
9. 검토용 상태로 전달하고 사용자의 승인 전에는 서비스에 적용하지 않는다.

## 7. 자동 검증 실패 조건

다음 중 하나라도 발생하면 결과를 통과시키면 안 된다.

- 공식 원형 path 개수가 `136개`가 아님
- 동일 정규화 후 원형과 결과의 path `d` 시퀀스가 다름
- 원형 path의 순서가 다름
- 눈 색 변경을 위해 새로운 path, rect 또는 overlay를 추가함
- 상단 두 눈 path가 아닌 다른 얼굴 디테일을 눈 색상으로 변경함
- 코·입 source index `130`, `131`, `132` 중 하나라도 `#683D11`이 아님
- 무늬 픽셀이 허용된 몸 마스크 밖에 존재함
- SVG 캔버스 또는 `viewBox`가 `155 x 155`가 아님
- 원형 그룹의 배치가 `(25, 30)`이 아님
- 좌표, 너비 또는 높이가 5px 그리드에 맞지 않음
- 투명 배경이 아님
- `shape-rendering="crispEdges"`가 없음
- 승인되지 않은 색상, 그라디언트, 블러 또는 안티앨리어싱 stroke를 사용함
- 사용자가 승인하지 않은 포즈나 실루엣 변경이 존재함

## 8. Skill과의 관계

하네스와 이 문서가 규칙의 원본이다. 전용 `cat-wholebody` Skill은
규칙의 원본을 대체하지 않고, 매 작업에서 두 문서를 읽고 6절의 절차와 7절의
검증을 실행하는 역할을 맡는다.

Skill에 규칙 값을 별도로 복사해 고정하면 문서가 갱신됐을 때 오래된 규칙을
실행할 수 있으므로, Skill은 항상 현재 프로젝트 문서를 먼저 읽어야 한다.

현재 이 문서는 Skill의 실행 계약을 정의하며, 전용 Skill은 프로젝트의
`AX design/skills/cat-wholebody/`에 구축되어 있다.

권장 요청 형식:

> `cat-wholebody` Skill을 사용해 첨부 레퍼런스 기반 고양이 에셋을
> 제작해줘. 공식 원형 잠금 모드로 작업해줘.

## 9. 승인 체크리스트

- [ ] 공식 원형 SVG를 기준으로 사용했다.
- [ ] 작업 모드를 원형 잠금 변형으로 선언했다.
- [ ] 레퍼런스에서는 허용된 속성만 추출했다.
- [ ] 원형 136개 path와 정규화된 기하 구조가 유지됐다.
- [ ] 새 무늬가 몸 픽셀 마스크 내부에만 존재한다.
- [ ] 눈 색을 변경했다면 기존 상단 두 눈 path의 fill만 변경했다.
- [ ] 코·입 세 path가 모두 `#683D11`을 유지한다.
- [ ] 표준 캔버스, 그리드, 배치, 투명 배경을 지켰다.
- [ ] 실제 크기와 확대 미리보기를 모두 검토했다.
- [ ] 자동 검증을 통과했다.
- [ ] 사용자 승인 전 서비스 에셋으로 승격하지 않았다.
