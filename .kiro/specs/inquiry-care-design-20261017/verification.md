# 문의 버튼·돌봄 도구 디자인

- 범위: 전체 메뉴의 AI 문의 버튼과 놀이터의 기록·돌봄 도구 영역.
- 기준: `docs/design.md`, `src/app/globals.css`, 기존 포퐁 에셋. Hallmark의 검수 지침을 기존 디자인 시스템 안에서 적용한다.
- 문의 버튼: 온보딩의 `animal-dog-qa.svg`를 재사용하고, 한 줄 14px 라벨과 56px 이상 터치 영역을 제공한다. 하단 메뉴·로그아웃과 거리를 두며 키보드 포커스와 움직임 줄이기를 유지한다.
- 돌봄 도구: 개별 티켓 장식 대신 하나의 목록에 위치·체크·기록 도트 아이콘을 배치한다. 모바일·태블릿은 세로 목록, 1024px부터 가로 목록으로 표시한다.
- 산책·준비물·병원 기록의 목적지, 사진 위치 공개 안내, 준비물의 기기 저장 안내는 유지한다.
- 문의 대화·전송 로직, 구매·게임 공개 설정은 변경하지 않는다. 비동기 대화 상태는 기존 문의창이 담당한다.
- 회귀 검증: 놀이터 진입·공유·돌봄 도구·문의 대화·전송 테스트 68개 통과. 변경 TSX 린트, 타입 검사, Next.js 운영 빌드 통과.
- Orca 내장 브라우저: 실제 CSS 너비 320·375·413·768·1440px에서 가로 넘침과 글자 잘림 없음. 모바일·태블릿 세로 목록과 데스크톱 3열을 확인했다.
- 문의 버튼: 기존 강아지 SVG 로딩, 14px 라벨, 57px 이상 버튼 높이, 클릭 시 문의창 열림, Escape로 닫힌 뒤 버튼으로 포커스 복귀와 포커스 테두리 표시를 확인했다. 실제 문의는 전송하지 않았다.
- 돌봄 도구: 세 링크 목적지 유지, 외출 준비함 클릭 시 실제 화면 이동을 확인했다. 로컬 프리뷰는 실제 개발 백엔드를 사용한 비로그인 검증이며 심사 계정 검증은 아니다.
- Hallmark 출처: <https://github.com/Nutlope/hallmark>, 설치 리비전 `13ac0ec7e148655948100b6396439e481361d690`.

## 검수 기준

기존 Pretendard·Cafe24와 노랑·브라운 토큰을 사용한다. 새 테마나 폰트를 추가하지 않는다. 버튼 상태는 배경·테두리로 구분하며 포커스는 즉시 표시한다. 요청한 두 영역만 변경하고 페이지별로 서로 다른 Hallmark 테마를 적용하지 않는다.

작은 기능별 차이는 기존 도트 에셋으로 표현한다. 변경 컴포넌트의 의미 구조·링크·키보드 동작을 코드와 Orca 내장 브라우저에서 검수했다.
