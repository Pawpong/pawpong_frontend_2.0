# 알림센터 정리와 채팅 읽음 연결

- 설정의 알림센터 링크, 전체 삭제 확인·취소·진행·오류 재시도 UI 추가함. 삭제 성공 뒤 누적 페이지와 헤더 배지 쿼리를 초기화함.
- 서버 페이지 계약에 맞춰 pageNumber/itemsPerPage로 조회함. 무한 스크롤 표식에 높이를 주고 브라우저가 자동 교차 감지를 늦출 때 사용할 더 보기 버튼을 제공함.
- 본인이 현재 채팅방을 읽었다는 서버 확인 뒤 알림센터·배지를 갱신함. 상대의 읽음이나 다른 방 이벤트에는 본인 알림을 초기화하지 않음. 다시 연 방에서도 읽음 요청을 보내 기존 채팅 알림을 정리함.
- 실제 격리 Nest API/Mongo를 연결한 Orca 402px 화면에서 설정 진입, 전체 삭제 확인·취소, 실패 시 모달 유지, 재시도 후 전체 25개 삭제·0개 표시, 다른 계정 25개 보존을 확인함. 다른 계정에서 더 보기 후 25개 고유 항목과 가로 넘침 없음 확인함.
- Node 전체 171개와 추가 읽음 이벤트 테스트 1개 통과함. 변경 파일 ESLint와 Next 빌드 통과함. 외부 FCM은 격리했으며 실제 기기 전달 시각이나 OS 알림 자동 삭제를 검증한 결과가 아님.
