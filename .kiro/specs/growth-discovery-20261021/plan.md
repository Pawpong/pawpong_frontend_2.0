# 포퐁 성장 개선 · 2026-10-21

## 이번에 연결할 사용자 경험

놀이 결과를 공유하면 같은 결과를 다시 열고 직접 놀이를 시작할 수 있다.
공개 게시글과 놀이 도구를 검색에서 발견할 수 있으며 가입·상담 신청까지 이어지는 행동을 측정한다.
기능 개수를 늘리는 것보다 발견 → 놀이 → 공유/기록 → 재방문 흐름의 끊긴 부분을 먼저 해결한다.

## 구현 범위와 완료 기준

- GTM: 가입 성공(sign_up), 신청 성공(generate_lead), 채팅방 열기, 공개 글 발행,
  놀이 완료, 실제 공유/복사를 구분한다. 실패·취소·단순 버튼 클릭을 전환으로 집계하지 않는다.
- 고정 이벤트·맥락만 허용한다. 사용자 ID, 닉네임, 메시지, 검색어, 사진 URL, 자유 입력값은 보내지 않는다.
  dev는 수집하지 않으며 로컬 debug만 명시적으로 허용한다.
- Android의 기존 screen-only 바이너리는 웹 이벤트를 중복 전송하지 않는다.
  신규 네이티브 이벤트 capability는 별도 앱 업데이트가 필요하다.
- 공유: 고정 카드 ID를 가진 공개 결과 페이지, 기존 포퐁 에셋/토큰/티켓 재사용,
  동일 결과 복원, 다시 놀이하기, 추억 카드 연결. 사용자 답변·사진은 URL에 싣지 않는다.
- SEO/AEO/GEO: 서버에서 읽을 수 있는 실제 본문, 고유 canonical/제목/설명,
  눈에 보이는 내용과 일치하는 구조화 데이터, 공개 콘텐츠 사이트맵.
  비공개·임시저장·심사 보류·탈퇴 작성자 글은 신규 검색 목록에서 제외한다.
- 검색용 API는 익명 전용 데이터만 반환한다. 앱 열람 동의 필터를 우회하지 않는다.
- 코드/DB/브라우저 검증 → 커밋 → dev 병합/배포 → 배포 확인 → 작업공간 삭제.
  이번 신규 기능의 운영 공개는 별도 승인 대상이다. 결제·다마고치 잠금은 그대로 유지한다.

## 후속 제품 우선순위

1. 이번 퍼널의 실제 사용량을 보고 놀이 완료 → 공유 → 재방문 이탈 구간을 개선한다.
2. 반려동물별 관심 주제와 저장한 준비물/기록의 계정 동기화, 활동 기반 주간 제안을 기획한다.
3. 검증 가능한 출처와 갱신일을 가진 생활 가이드, 장소별 실제 경험을 연결한다.
4. 다마고치는 별도 품질 승인 후 공개한다. 결제·예약·의료 상담 등은 별도 계약과 운영 검증이 필요하다.
