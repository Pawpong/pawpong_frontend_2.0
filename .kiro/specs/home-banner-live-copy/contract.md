# 메인 배너의 선명한 문구 · 2026-10-07

AI 배너 이미지에 구운 한글은 자소가 뭉개지고 확대 때 흐려진다. 기존 도트 그림의 색과 캐릭터를 유지한 글자 없는 원화 위에 Cafe24 PRO UP 웹 폰트와 기존 Pawpong SVG 로고를 표시한다.

`BannerDto.textOverlay`는 optional/null이며 layout(welcome/launch/category), headline(1..40), subtitle(0..60), ctaLabel(0..24)로 구성한다. 기존 이미지 배너는 metadata가 없으면 이전처럼 표시한다. 배너 전체는 기존 linkType/linkUrl의 단일 링크이고 CTA는 별도 중첩 링크가 아니다. 글자는 React의 텍스트로 렌더링하여 접근성 이름과 브라우저 확대를 보존한다. 서버에서 생략은 보존, null은 metadata 삭제다.

관리자에는 선명한 글자 토글, 세 가지 배치와 PC/모바일 미리보기를 제공한다. 글자가 이미 있는 원화에는 토글을 끈다. 이미지·문구를 함께 바꾼다.

## 원화

- 스킬: imagegen, 내장 이미지 편집 도구.
- 원본: 사용자의 포퐁_배너통합_리뉴얼시안_20261006 중 환영 버터가든, 출시 버터옐로우, 강아지 피치산책, 고양이 라벤더쉼터, 도마뱀 민트테라리움.
- 편집 지시 요약: 원래 도트 동물의 전신·표정·색과 파스텔 배경을 보존하고 모든 글씨·로고·버튼을 지워 실제 폰트 문구를 위한 공간을 남긴다. 새 글자나 마크를 생성하지 않는다.
- 결과: public/images/banners/live-copy-v1/*.png. 각 원화의 바이트는 변경하지 않았다. 모바일은 동일한 중심 구도의 그림을 기존 375:191.6667 프레임으로 표시하며, 390px Orca 검수에서 세 캐릭터가 잘리지 않음을 확인했다.

## 반영 순서

배너 API metadata → 웹 렌더러와 관리자 → dev 전용 배너 콘텐츠 원자적 갱신. 환영 노랑 0, 출시 노랑 1, 강아지 2, 고양이 3, 도마뱀 4. ID·링크·대상·비노출 시안을 보존한다. dev DB만 연결하고 갱신 전 원문과 비교하여 다른 편집자의 변경을 덮어쓰지 않는다. 운영은 변경하지 않는다.

## 검증

서버: 실제 ValidationPipe와 격리 MongoDB로 잘못된 metadata 거부, 저장→공개/관리자 조회, 다른 필드만 수정 시 문구 보존, null 삭제, 기존 이미지 응답 호환. 프론트: 기존 전체 테스트·타입·빌드와 Orca PC/390px 실렌더 검수. 별도 임시 preview 경로는 커밋에서 제외한다. 배포 후 실제 dev API와 홈에서 순서·텍스트·링크를 다시 확인한다.
