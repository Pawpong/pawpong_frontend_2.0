# AI 게시글 비교 선택

- AI 생성 결과·보관함에서 원본 비교 공개를 기본 해제함. 선택하지 않으면 결과 한 장만 전달·업로드하며, 선택하면 결과와 본인 원본 두 장을 함께 전달함.
- 게시글의 비교 메타데이터를 피드·마이홈 카드·상세에 전달하고 공통 슬라이더로 표시함. 추가 사진은 함께 표시하며 상세 링크·댓글 액션을 유지함.
- 슬라이더는 range 입력으로 터치/마우스/키보드 조작을 지원하고 현재 원본 비율을 스크린리더에 제공함. 세로 스크롤을 허용함.
- 작성기의 두 사진 삭제 후 비교 해제와 수정 시 인덱스 재계산은 CommunityPostEditor에 연결함. 다른 에이전트의 분류 UI 작업과 같은 작성기 파일에 통합함.
- Orca iPhone 폭402px 브라우저와 실제 Nest8086·인메모리 DB·스토리지에서 결과 한 장 업로드, 비교 두 장 업로드/저장, 타인 상세 슬라이더, 범위80% 조작, 원본 삭제 후 비교 해제·결과만 저장을 검증함. 실제 iPhone WKWebView 터치나 운영 게시글 생성은 수행하지 않았음.
- FE TypeScript·변경 파일 ESLint·Node152개와 BE 비교/작성/공개범위 E2E33개 및 기존 unit29개 통과함.
