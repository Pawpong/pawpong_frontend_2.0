# AI 게시글 분류·비교 편집 검증 (2026-10-03)

## 동작

- 새 글의 글·첫 사진이 바뀌면 1.2초 debounce 후 자동 분류함. 서버 제한에 맞춰 요청 간격은 최소 11초로 유지함.
- 직접 선택한 카테고리와 수정 화면의 기존 카테고리를 존중함. 입력 변경·직접 선택·화면 이탈 시 이전 응답 적용을 취소함.
- 작성·수정에서 원본 비교 공개를 켜고 끌 수 있음. 비교를 끄면 연결했던 원본을 게시글 사진 목록에서도 제외함.
- AI 결과만 가져온 새 글도 생성 작업 ID로 원본을 연결함. 기존 결과 전용 게시글은 보관함에서 같은 AI 사진을 고르거나 원본을 직접 첨부함. 이전 게시글에는 생성 작업 ID가 없어 자동 매칭을 보장하지 않음.
- 원본 교체·사진 삭제·URL/File 업로드 순서 변경 시 비교 인덱스를 다시 계산함. 원본까지 최대 10장으로 제한함.
- 화면 명칭을 포퐁 AI로 통일함. 개인정보처리방침에는 실제 기능 제공업체를 함께 명시함.

## 검증

- `node --test tests/*.test.cjs` 191개와 `node --test tests/sentry-environment.test.mjs` 6개, 총 197개 통과함.
- `pnpm type-check`, 변경 파일 ESLint, `pnpm build` 통과함.
- Orca 브라우저와 격리 Nest API/MongoMemoryReplSet에서 실제 작성·수정·타 사용자 조회를 검증함. 외부 푸시·운영 DB는 사용하지 않음.
- 보관함에서 AI 결과만 글쓰기로 가져온 뒤 비교를 켜면 원본 조회 및 슬라이더가 표시됨.
- 402px 모바일 화면에서 두 사진이 로드되고 가로 넘침이 없음을 확인함. range 입력 20%·75%에 따라 실제 clip-path와 손잡이 위치가 변경됨.
- 글을 등록하면 다른 계정 조회에서 사진 2장과 비교 정보가 반환되고 슬라이더가 표시됨.
- 기존 비교 글에서 토글을 끄고 저장하면 타 계정 조회에서 결과 사진 1장만 표시되고 슬라이더가 제거됨.
- 결과 전용 글을 다시 수정해 보관함 원본을 연결하고 저장하면 타 계정 조회에서 비교 인덱스 `{beforePhotoIndex: 1, afterPhotoIndex: 0}`과 사진 2장이 반환됨.
- 글 내용에 따라 분류 API가 버튼 없이 호출되고 파충류가 자동 선택됨. 직접 선택한 고양이는 글 수정 후에도 유지됨. 분류를 해제한 수정은 `petType: null`을 전송함.
- 브라우저 검증의 동물 분류 응답은 결정적인 fixture임. 실제 모델 호출 검증은 백엔드 문서에 별도 기록함. 새 iOS/Android 바이너리나 실기기 검증을 수행한 결과는 아님.

## 반영 범위

- 최신 `origin/dev`를 반영한 기능 브랜치에서 검증함. PR 대상은 dev임.
- 원본 비교 기능은 기존 API 계약을 사용함. 카테고리 해제는 백엔드의 nullable `petType` 변경과 함께 사용함.
- main 병합·운영 배포·스토어 제출은 최신 운영자 지시에 따라 수행하지 않음.
