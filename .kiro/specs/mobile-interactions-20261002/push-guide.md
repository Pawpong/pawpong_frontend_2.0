# 앱 푸시 안내와 기존 알림 발송 보완

- 기존 createNotification 경로의 상담 완료·입양 승인·거절 알림도 DB에 저장한 제목·본문·이동 경로를 FCM으로 전달함. 빌더 경로는 기존 withPush 설정을 유지해 중복 발송하지 않음.
- GET /api/v2/notification/push-status는 JWT의 본인 계정만 조회하며 registered 불리언만 반환함. 토큰 값이나 다른 기기 정보를 공개하지 않고 private, no-store를 적용함.
- 현재 출시 앱에는 권한 조회 브리지가 없어 등록 상태만 참고함. 등록된 토큰의 존재는 OS 알림 허용이나 현재 기기의 상태를 보장하지 않음. 등록 누락 앱에는 포퐁 공통 모달로 설정 경로·재등록 안내를 제공하며 닫을 수 있음. 같은 웹 세션에서 닫은 안내는 하루 동안 반복하지 않음.
- 다음 RN 코드에는 알림 권한 조회/설정 열기 capability를 준비함. capability 없는 구 앱에는 새 요청을 보내지 않으며 조회 실패를 권한 거부로 간주하지 않음.
- 관련 단위 검사 8개와 실제 Nest/격리 Mongo의 푸시 소유권·개인 등록 상태 계약 9개 통과함. 기존 테스트 fixture에 빠진 userRole·관리자 발송 목적(service)을 실제 계약에 맞춰 보완했으며 인증/마케팅 정책은 완화하지 않았음.
