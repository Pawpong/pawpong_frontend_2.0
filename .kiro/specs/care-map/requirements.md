# 우리 동네 돌봄 지도

홈/탐색의 지도 배너 또는 전체 메뉴 → `/care-map` → 지역·시설 검색 또는 내 위치 → 지도 핀/목록 선택 → 상세 정보·전화·길찾기 서비스 선택.
`/care-map?kind=shelter`는 보호·입양시설부터 연다. 로그인은 필요 없다.

- 카카오 지도 SDK는 지도 화면에서만 로드한다. 기존 카카오 공유 SDK와 분리한다.
- 공개 JavaScript 키는 기존 API base URL의 `/api/v2/care-map/config`에서 읽는다. REST 키는 프론트에 전달하지 않는다.
- 기본 조회는 전국 등록 목록이다. 시작 시 브라우저가 위치 권한을 이미 허용한 경우에만 내 주변을 자동 조회하며, 새 권한 요청은 내 위치 버튼을 눌렀을 때만 한다. 초기 지도 중심인 서울시청을 사용자 위치로 표시하지 않는다.
- 검색 범위(전국·선택 지역 등록 목록 / 확인한 내 위치 주변 / 검색한 지도 중심 주변)와 진료 조건(전체 병원 / 공식 2차·의뢰 진료 확인)은 독립적이다. 검색어 제출·지우기와 진료 조건 변경은 현재 범위·좌표·반경을 유지한다.
- 주변 반경의 초기값은 병원 5km/보호센터 20km이며 3·5·10·20km를 선택할 수 있다. 반경 변경은 마지막으로 검색한 기준 좌표를 유지한다. 지도 이동이나 목록·핀 선택으로 움직인 화면 중심은 '이 지역에서 다시 검색'을 눌러야 새 검색에 반영한다.
- 지역 선택은 해당 등록 목록으로 명시적으로 전환하고 검색어·진료 조건을 유지한다. 종류 변경은 범위·검색어·반경을 유지하며 보호센터로 바꾸면 병원 전용 의뢰 조건만 해제한다. 조건 변경은 페이지를 1로 돌리고 시설 선택을 해제한다. '조건 초기화'는 현재 시설 종류의 전국·전체 목록으로 돌아간다.
- 전체 동물병원과 공식 의뢰 진료 안내가 확인된 일부 병원을 구분한다. 확인 목록은 전국 2차 병원 전수 자료가 아니며, 표시가 없거나 근거가 없는 병원을 1차로 분류하지 않는다.
- 전국·지역 목록은 국가동물보호정보시스템 등록자료, 주변 검색은 카카오 장소 정보를 사용한다. 보호센터 지역은 관할 지자체 기준이며 실제 시설은 다른 지역에 있을 수 있다. 현재 진료·보호동물·방문 가능 여부는 별도로 확인한다.
- 반응형 지도·목록, 양방향 선택, 상세 정보, 전화, 카카오맵·네이버지도·구글지도 길찾기 선택, 확대·축소, 페이지, 빈 결과, 오류 재시도를 제공한다. 핀은 현재 목록의 좌표가 확인된 시설만 표시하며 거리는 검색 기준점부터의 직선 거리다.
- 새 조회 조건은 독립 query key와 abort signal을 사용해 이전 요청이 새 결과를 덮지 않게 한다.

- `pnpm type-check`, 변경 파일 ESLint, `pnpm build`
- `node --test tests/care-map-sdk.test.cjs`: 중복 로드, 공유 SDK와 구분, 실패/타임아웃 재시도
- `node --test tests/care-map-search.test.cjs tests/care-map-location.test.cjs tests/care-map-recovery.test.cjs`: 범위·진료·검색어 조합과 API 요청, 반경 기준점 유지, 페이지·선택 초기화, 위치 권한·취소, 오류 복구
- Orca 브라우저: 실제 SDK 타일/핀, 장소 검색, 보호시설 전환, 진료의뢰 근거, 상세 링크, 390px 반응형, 위치 검색/거절, 페이지네이션, 빈 결과

## 배포 범위

검증한 지도 변경은 최신 대상 브랜치를 반영한 별도 PR로 dev에 먼저 반영한 뒤 지도 커밋만 main으로 선택 승격한다. dev 전용 다마고치가 섞인 dev 전체를 main에 병합하지 않는다.
`https://dev.pawpong.kr/care-map`과 `https://pawpong.kr/care-map`의 실제 공개 API·SDK 동작을 확인한다. 실제 GPS 권한 허용 검증과 고정 좌표·권한 거부 검증은 구분해 보고한다.
