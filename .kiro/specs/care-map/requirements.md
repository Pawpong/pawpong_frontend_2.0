# 우리 동네 돌봄 지도

홈/탐색의 지도 배너 또는 전체 메뉴 → `/care-map` → 지역·시설 검색 또는 내 위치 → 지도 핀/목록 선택 → 상세 정보·전화·카카오 길찾기.
`/care-map?kind=shelter`는 보호·입양시설부터 연다. 로그인은 필요 없다.

- 카카오 지도 SDK는 지도 화면에서만 로드한다. 기존 카카오 공유 SDK와 분리한다.
- 공개 JavaScript 키는 기존 API base URL의 `/api/v2/care-map/config`에서 읽는다. REST 키는 프론트에 전달하지 않는다.
- 기본 검색은 서울시청 중심, 병원 5km/보호시설 20km다. 시작 위치를 사용자에게 알리고 위치 권한은 내 위치 버튼을 눌렀을 때만 요청한다.
- 검색어 입력은 전국 검색, 이 지역에서 다시 검색은 지도 중심의 선택 반경 검색이다. 거리는 직선 거리로 표시한다.
- 전체 동물병원과 공식 의뢰 진료 안내가 확인된 일부 병원을 구분한다. 병원 이름으로 1차/2차 등급을 추정하지 않는다.
- 보호시설은 카카오 등록 장소 정보다. 지자체 지정 여부와 현재 보호동물은 별도 확인하며 국가동물보호정보시스템으로 연결한다.
- 반응형 지도·목록, 양방향 선택, 상세 정보, 전화, 카카오 길찾기, 확대·축소, 더 보기, 빈 결과, 오류 재시도를 제공한다.
- 새 조회 조건은 독립 query key와 abort signal을 사용해 이전 요청이 새 결과를 덮지 않게 한다.

## 배포 범위
