# 놀이터 생활 도구 · 2026-10-07 dev

## 목적과 연결

Obsidian `Projects/Pawpong/슈퍼앱_dev_개선_20261007.md`의 사진 → 기록 → 장소 → 놀이 흐름을 구현한다. 놀이터에서 외출 준비함과 추억 카드로 진입하고, 산책·병원·일상 기록은 기존 커뮤니티 작성 화면으로 연결한다. 기존 배지 계산과 AI 이용 횟수, 인앱결제 잠금, 반려동물 키우기 공개 잠금은 변경하지 않는다.

## 외출 준비함

- `/playground/outing`: 산책·카페·여행·병원별 기본 준비물과 최대 12개 사용자 항목, 체크, 항목 삭제, 텍스트 복사.
- 체크만 비우기는 사용자 항목을 보존한다. 모든 준비함 지우기는 확인 후 현재 소유자의 저장 키만 삭제한다.
- 데이터는 현재 브라우저 localStorage에만 저장한다. 계정별 키와 로그인 전 공용 키를 분리하며 세션 변경 시 이전 계정 화면을 재사용하지 않는다.
- 다른 탭 변경을 읽고 편집한다. 브라우저 저장 차단·용량 초과 시 현재 화면 편집은 보존하고 저장되지 않았음을 알린다.
- 산책/병원/일상 링크는 `experience=walk|clinic|daily`로 새 글의 기록 틀만 선택한다. 실제 기록 값, AI 동의, 글 발행은 커뮤니티의 기존 계약을 따른다.

## 오늘의 추억 카드

- `/playground/memory-card`: 20MB 이하 사진, 이름, 날짜, 한 문장, 버터·민트·라벤더 3종 테마, 확대/좌우/상하 조절.
- 기존 사진 처리기로 EXIF 방향을 반영하고 메타데이터를 제거한다. HEIC는 기존 변환 경로를 사용하며 움직이는 사진은 한 장으로 만든다.
- 1080×1350 PNG의 글자는 실제 서비스 폰트로 그린다. 로고와 발바닥은 기존 정식 자산을 재사용한다.
- 브라우저 내부에서만 사진을 처리하며 서버 업로드·계정 저장·AI 호출은 하지 않는다. 화면 이탈과 계정 변경 시 사진·문구를 폐기하고 object URL을 해제한다.
- Web Share 파일 공유 지원 시 공유 선택창을 사용하고, 미지원이면 PNG 다운로드로 안내한다. 취소/오류가 성공으로 표시되지 않게 한다.
- 비동기 사진 처리와 내보내기는 요청 순서·계정 소유자를 확인하고 오래된 결과를 적용하지 않는다. 중복 내보내기를 잠근다.

## 사진 준비 완료 처리 보완

Orca에서 이미지 `load`와 canvas 출력은 완료됐지만 `Image.decode()`가 계속 대기하는 현상을 실제 JPEG로 재현했다. 공용 사진 로더는 `load`/`error`와 30초 제한으로 완료를 판정한다. 오류·시간 초과 후 핸들러와 자원을 해제하며 기존 HEIC 대체 경로와 원본 GIF/AVIF 보존 계약은 유지한다.

## 검증 범위

- 목적별 항목 보존, 잘못된 저장 데이터, 계정 키 격리, 다른 탭 변경, 저장 차단, 날짜·크롭 경계와 파일명 개인정보 제외를 단위 검증한다.
- 실제 Orca 화면에서 항목 추가/체크/새로고침/목적 전환/체크 비우기, 사진 선택·문구/테마 변경·PNG 출력·모바일 너비를 확인한다.
- 실기기 공유 시트와 HEIC 네이티브 디코더 지원 여부는 브라우저별 차이가 있으므로 확인 범위를 결과 보고서에 구분한다.
