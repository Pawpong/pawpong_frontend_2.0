# 브리더 등급 정책 화면 아카이브

## 상태

- 2026-08-31 기획 결정으로 `New`/`Elite` 브리더 등급제를 폐기했다.
- `/grade-policy`와 `/grade-policy/apply`는 현재 `404`를 반환하며 검색 노출도 차단한다.
- 등급을 대체할 EXP/RPM 정책은 확정되지 않았으므로 서비스 코드에 추정 구현을 두지 않는다.

## 보존 범위

- 삭제 전 화면 소스는 Git 커밋 `7a56ca9`의 `src/app/(main)/grade-policy`에서 복구할 수 있다.
- 디자인 구조가 필요하면 Figma `2026-pawpong` 파일의 당시 등급 정책 화면을 시각 참고로만 사용한다.
- 향후 성장 지표 정책이 확정되면 용어, 산식, 획득·차감 조건, 노출 위치, 이의 제기 절차를 먼저 문서화한 뒤 새 기능으로 구현한다.

## 현재 서비스 기준

- 브리더 신뢰 표시는 인증 상태(`pending`, `reviewing`, `approved`, `rejected`)와 실제 사업자·활동 정보로 구성한다.
- 요금제(`basic`, `pro`)는 기능 플랜이며 브리더의 우열이나 신뢰 등급으로 표현하지 않는다.
- 기존 DB의 `verification.level`은 데이터 호환 목적으로만 잠시 보존하며 신규 UI/API 계약에서 사용하지 않는다.
