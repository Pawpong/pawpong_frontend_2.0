# pawpong-pixel-icon / pawpong-pixel-icon-gray 스킬 작업

- 작성자: 최은진
- 날짜: 2026-08-23
- 범위: 포퐁 픽셀 아이콘 제작 스킬 2종(`pawpong-pixel-icon`, `pawpong-pixel-icon-gray`)과
  이 스킬들로 제작한 아이콘들

## 요청 배경

기존 `pawpong-pixel-icon` 스킬(브랜드 컬러 3토큰 채움 + 스트로크 2종, 총 3개 산출물을
만드는 스킬)로 신규 아이콘 3종(돋보기·커뮤니티·글작성)을 제작했다. 이후 "브랜드 컬러
없이 회색 하나로만 된 아이콘"을 만드는 별도 스킬이 필요해져 `pawpong-pixel-icon-gray`를
새로 만들었는데, 처음 요구사항 파악이 두 번 어긋나서(① 스트로크 버전으로 오해 → ②
"이미 있는 아이콘 재색칠"로 오해) 사용자가 두 차례 정정해준 끝에 최종 형태로
정착했다. 이 최종 스킬로 투표 아이콘을 제작했다.

## 진행한 작업

### 1. `pawpong-pixel-icon`으로 제작한 아이콘 3종

모두 채움 1개 + 스트로크(`#AD651D`, `#6B6B6B`) 2개 + 대비 배경 검증본까지, Figma
"Brand System — Pixel Icons" 페이지에 기존 하트·별·북마크와 같은 규칙(35×35 캔버스,
unit = 35 ÷ 최장변, 좌우 대칭 검증)으로 배치하고, 대응하는 grid 데이터를 HTML 브랜드
시스템 문서에도 반영했다.

- **돋보기(magnifier)**: 손잡이 형태를 사용자 피드백에 따라 여러 번 조정했다 — 얇은
  4픽셀 대각선 → (참고 이미지 요청으로) 굵은 2블록 대각선 → 다시 얇은 대각선으로
  되돌림 → 픽셀 3개로 축소, 최종 9×9 격자.
- **커뮤니티(community)**: 임의로 디자인하지 않고, 실제 코드(`NavCommunityIcon`)의
  SVG 경로를 라스터화해서 3인 그룹 실루엣을 추출 — 17×12 격자.
- **글작성(write)**: 코드베이스에 전용 아이콘이 없어(현재는 범용 `PlusIcon`을 재사용
  중) BX 디자이너 관점에서 연필 모티프로 새로 디자인 — 17×15 격자.

### 2. `pawpong-pixel-icon-gray` 스킬 신설 — 두 차례 정정

- **최초 버전(오해 1)**: "이미 있는 아이콘의 stroke `#6B6B6B` 버전만 별도로 만드는"
  스킬로 설계 — 사용자가 "stroke가 아니라 기본형(채움) 아이콘을 원한다"고 정정.
- **1차 수정(오해 2)**: "브랜드 버전 없이 그레이 3토큰(outline `#6B6B6B` / highlight
  흰색 / fill `#A6A6A6`)으로 처음부터 독립 제작"으로 재설계 — 사용자가 "3토큰이 아니라
  단일 색상 하나로"라고 다시 정정.
- **최종 형태**: outline·highlight·fill 구분 없이 실루엣의 모든 셀을 단일 토큰
  `#6B6B6B` 하나로 채우는 "기본형 그레이 단색" 스킬로 확정. 브랜드 버전·스트로크
  버전은 절대 만들지 않고, 그리드 레이아웃 규칙(캔버스·유닛·대칭 검증)만 브랜드
  아이콘과 동일하게 따른다.

### 3. `pawpong-pixel-icon-gray`로 제작한 아이콘

- **투표(vote)**: 코드의 `VoteIcon`(투표함 + 다이아몬드형 투표용지) SVG를 브라우저로
  정확히 렌더링해서 확인한 뒤 13×16 격자로 추출, 좌우 대칭 검증. 단일 토큰
  `#6B6B6B`로만 채워 harness에 신규 섹션("기본형 — 그레이 단색")으로 배치.

## 확인/검증

- 아이콘마다 좌우 대칭 격자를 수기로 검증했다(대칭이 필요 없는 방향성 요소 —
  돋보기 손잡이 등 — 는 의도적 비대칭으로 명시).
- Figma 스크린샷을 PIL로 확대(nearest-neighbor)해서 실루엣을 육안으로 확인했다.
- 흰 배경 + 회색 체커보드 배경 두 군데에서 대비 검증(흰색 하이라이트 픽셀이 실제로
  채워졌는지)을 거쳤다.
- 커뮤니티·투표 아이콘은 실제 앱 소스(SVG)를 근거로 추출했음을 코드에서 직접
  확인했다 — 임의 디자인이 아니다.
- **미확인**: 이번 작업은 Figma·HTML 브랜드 문서 단계까지만 진행했고, 아이콘을
  실제 프로덕션 코드(`src/shared/assets/icons`)의 SVG 컴포넌트로 반영하는 작업은
  하지 않았다.

  다만 산출물은 항상 단일 톤 기본형 하나뿐이다.
